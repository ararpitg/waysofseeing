# Ways of Seeing — An Indigenous Media Archive

A static site: plain HTML, CSS, and JavaScript, no build step.

- `index.html` — the page
- `assets/js/wos-data.js` — every catalog record (add records here; IDs `WOS-###` are permanent and never reused)
- `assets/js/wos-catalog.js` — renders the catalog, the Readings bibliography, and the counts from the data file
- `assets/css/style.css` — styles

The archive links to work where its makers host it and does not re-host anyone else's media.
Curated by Arpit Gaind, with gratitude to the AKHRA collective, Ranchi. Contact: contact@arpitgaind.com
